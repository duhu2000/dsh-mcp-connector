# #181 全新 generation 安装验收

## 变更

0.2.80 将 Zod 从 peer/dev 依赖移至正式 dependencies，范围 ^4.1.8。
React、React DOM 和 @deepseek-ai/* 保留宿主 peer；不修改宿主校验、asar、共享 profile 或安全边界。
旧测试辅助脚本不再把宿主 Zod 链接进插件目录。

## 可重复验收

Node 24 + pnpm 11.1.1，执行 `node scripts/check-fresh-install.mjs`。
脚本真实打包候选版本并下载官方 0.2.79 对照包，在操作系统临时目录分别创建全新 profiles/.generations/staging。
关闭自动 peer 安装和安装脚本，使用 hoisted 布局；不存在 profiles/node_modules，清除子进程 NODE_PATH/NODE_OPTIONS。
安装后将 staging 改名为 live，检查实际模块解析及 realpath，而非仅比较 manifest。

- 0.2.79 对照：插件位置无法解析 Zod，重现缺少 generation 自有依赖的前提。
- 修复包：Zod realpath 位于提升后的 live 目录；不是宿主或其他目录的软链接。
- 实际发布包的 schema.js 与 local-overrides.js 导入成功；Zod record 解析通过。
- 未安装其他宿主 peer，因此不是完整 DSH 启动验收；migration 的宿主集成由完整回归测试覆盖。
- 本机完整 check：454 tests，446 pass，8 skip，0 fail；90 发布文件校验通过。
- CI 新增 Windows/Linux 相同隔离安装门禁，并成为 PR 打包的前置条件。
