# 本机连接统计范围（PR #195）

本阶段仅提供当前 profile 的本机统计，不提供社区总量、独立用户数或热门排序。
没有上报服务、参与开关、随机统计实例 ID、网络请求或待上报队列。
此前社区实验源文件及其测试已从当前工作树移除；Git 历史不因此擦除。

## 计数口径

- 计数单位是公开目录卡片，不是连接次数、Server 数量或用户人数。
- 仅 connect/configure 最终返回成功时记录；不等价于业务工具调用成功。
- 同一卡片只记录首次成功。重连、升级、重新授权不重复累计，断开不扣减。
- 启动时已有的目录连接作为历史基线，不能直接推定成功；之后连接成功仍不计入新增。
- 近 30 天新增为非历史基线卡片的首次成功，不是最近 30 天所有成功操作。
- 不记录自定义/JSON 资源的凭据、URL、业务内容；仅保存卡片 ID、时间和基线标记。
- persistSecrets=false 时只保存在内存，重启即清空；持久化沿用当前 profile 的存储域。

## 故障边界

连接响应不等待统计写盘。历史基线同样后台写入，并排在新成功记录之前。
串行队列最多保留 128 个待处理操作，单个操作超时为 1 秒。
写入失败、超时或队列满后停止本轮统计；界面显示不可用，不返回虚假的完整统计。
Host 释放时停止接受统计写入。已交给存储层的写入不能撤回，晚到结果不恢复内存计数。
统计不是审计账本，异常退出或存储异常可能丢失尚未保存的记录。

## 验收要求

自动化覆盖去重、重启恢复、30 天窗口、历史基线、错误/回滚不计数、私有信息排除、
写盘失败/挂起/晚到、队列上限、释放、社区 API 拒绝与 UI 范围。
本地自动化和源代码检查不代替真实 UI 或 Windows Desktop 验收。
维护者已批准合并及发布；以发行 CI 和打包检查为门禁，实机反馈仍独立跟踪。
