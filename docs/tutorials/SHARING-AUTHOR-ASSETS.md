# 分享体验作者素材索引

分享前，先选与自己要说明的事情对应的素材，并标注来源版本、验证范围和日期。涉及个人体验时，由作者根据亲自观察到的结果填写。

| 要说明的内容 | 可引用的素材 | 引用范围 |
|---|---|---|
| 一次企业简介查询 | [首次成功案例](ONE-SUCCESS-CASE.md) | 2026-10-16 在已有连接上完成一次只读调用。引用已公开的脱敏结论，并说明这次验证使用已有授权。 |
| 导入配置 | [JSON 迁移教程](JSON-MIGRATION.md) | 可引用操作步骤、预期状态和合成测试范围。要描述某个服务的实际调用结果，需要该服务的独立验证。 |
| 发现失败后的处理 | [工具查找与恢复](TOOL-SEARCH-RECOVERY.md) | 说明缓存、重新发现和排障步骤。将连接恢复与实际业务调用的验证结果分开记录。 |
| 组织一篇体验分享 | [社区分享素材包](SHARING-KIT.md) | 提供提纲、披露方式和人工记录方法，最终内容由作者编辑。 |
