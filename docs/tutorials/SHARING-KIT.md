## 可引用的简短介绍

> dsh-mcp-connector 是 DeepSeek Harness 的开源 MCP 接入与管理插件。通过连接器目录或已有配置接入 MCP Server，管理授权、跨连接查找工具并排查连接问题。由企查查/QCC 团队维护，支持通用 MCP 服务；具体数据权限、额度与费用由各服务商决定。

安装命令、Desktop/Web 重启说明见[统一入口](README.md)。项目地址：[GitHub](https://github.com/duhu2000/dsh-mcp-connector)，安装包：[npm](https://www.npmjs.com/package/dsh-mcp-connector)。

## 文章提纲与标题方向

可选标题：“我如何在 DSH 中找到并调用一个 MCP 工具”；只有实测后才使用“成功”“节省了多久”等结论。

1. 原先卡在哪里：配置分散、找不到工具或连接失败。
2. 你的环境与步骤：版本、宿主、安装、授权、选定任务。
3. 你的证据：实际调用结果摘要、来源、时间；不要只截图“已连接”。
4. 你的判断：有效之处、失败之处、费用与权限门槛。
5. 给读者一个下一步：安装入口与同一任务的复现链接。

如受邀测试、获得试用额度或与项目有关系，应主动说明；欢迎独立评价，不要求正面结论。不要宣传保证排名第一、所有服务免费、一键免权限或未经测量的效率提升。

## 分享后怎样改进

自愿提交脱敏案例或问题到 [Issues](https://github.com/duhu2000/dsh-mcp-connector/issues)。希望参与开发可看[贡献指南](../../CONTRIBUTING.md)。Star 表达认可，Fork 用于实际修改与贡献，都不是使用条件。

首轮邀请 5–10 位自愿体验者，手工记录安装、授权、工具发现、首次调用各阶段的成功/失败/未测试、实际耗时和阻塞原因。未计时不补估值，不新增遥测；样本仅用于改进体验，不外推整体转化率。npm 下载量也不等于独立用户或成功调用人数。

作者在引用案例、教程、截图或 GIF 前，应先查看[分享体验作者素材索引](SHARING-AUTHOR-ASSETS.md)，区分历史真实只读摘要、流程/合成测试和 Mock 界面素材。应用内草稿模块的 P0 接入契约见[分享体验模块接入说明](SHARING-UI-INTEGRATION.md)。
