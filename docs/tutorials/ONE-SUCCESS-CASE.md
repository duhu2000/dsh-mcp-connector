# 首次成功案例：查询一家企业的简介

目标：在正常 DSH 会话中完成一次有来源、可核对的只读调用。插件支持通用 MCP 服务；这里用企查查作为具体示例，不要求每位用户都使用该服务。

## 准备与连接

1. 按[安装入口](README.md)安装并重启对应宿主，记录页面显示的插件版本。
2. 在市场找到“企查查·企业工商”，连接到你希望使用的项目范围，按页面完成服务商授权。
3. 确认账号具备企业简介接口权限与额度。插件开源不等于服务商数据免费，费用和可用范围以服务商账号为准。
4. 在“工具”页定位 `qcc-company` 的 `get_company_profile`，查看当前参数和来源。没有该工具时先检查授权及工具发现状态，不要凭名称猜测或改用其他工具。

已授权账号可以复用有效授权；是否出现授权页面不能单独证明账号或权限正确。缓存中的工具列表也不证明当前能调用。

## 可复制的任务

在正常 DSH 会话中发送以下内容，通过 Host 的工具权限与审批链执行：

> 使用 qcc-company 的 get_company_profile，只查询“企查查科技股份有限公司”的企业简介（searchKey 为完整企业名称）。仅调用一次；不要查询联系人、司法、财务或其他主体，不要写入任何数据。成功后列出实际返回的企业名称、简介摘要、数据来源和调用时间；缺失字段标为未返回。失败则报告错误，不自动扩大查询或连续重试。

## 怎样判定完成

| 检查层级 | 通过条件 |
|---|---|
| 连接 | 正确范围内存在连接，授权状态可用 |
| 工具 | 发现预期工具，来源和参数可核对 |
| 业务 | 本次调用成功，返回企业名称与目标一致；有真实来源与时间 |

只有第三层通过才记为本次首次成功。授权失败看[OAuth 诊断](OAUTH-DIAGNOSTICS.md)；工具缺失看[查找与恢复](TOOL-SEARCH-RECOVERY.md)；额度或业务权限不足应按服务商提示处理。
