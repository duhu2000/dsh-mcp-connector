# 在连接器市场按分类查找服务

打开「市场」后，默认的「全部」视图先列出推荐卡片，再按业务分类展示连接器。搜索词同时作用于推荐和各分类。每个有匹配结果的业务分类先显示最多 4 张卡片，点击「查看全部」可在原处展开。也可以直接点击分类标签，查看该分类下所有匹配项。

「推荐」展示当前目录中与客户端推荐列表匹配的卡片。推荐卡片也会出现在自己的业务分类中。如果在「推荐」里找不到某个服务，可以切回「全部」搜索。

## 贡献卡片时如何填写分类

在描述符的 `category` 中使用下列中文名称之一。按用户使用这项服务要完成的主要任务选择分类。

企业数据、金融投资、法律合规、开发工具、办公协作、调研分析、设计创意、效率工具、其他。

客户端兼容已有目录中的旧名称，例如「金融数据」显示为「金融投资」，「法律数据」显示为「法律合规」，「数据采集」显示为「效率工具」。无法识别的分类归入「其他」。

新提交的卡片将 `featured` 设为 `false`。推荐位由维护者管理。仅修改这个字段不会让卡片出现在客户端的「推荐」列表。提交入口和验证步骤见[连接器上架指南](ONBOARDING.md)。
