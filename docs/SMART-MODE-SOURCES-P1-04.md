## 指纹与候选

完整指纹覆盖整个原始 MCP 工具对象：原始名称、输入 schema、默认值、examples、const、输出 schema、annotations、execution、描述和扩展元数据。只对对象键排序，保留数组顺序及实际 JSON 值，不清洗、裁剪或补默认值；不支持的非 JSON 值和超限定义明确拒绝。

另有候选指纹，仅排除 title/description，用于找出调用契约相同的观察项。**候选不是业务等价证明，也不会生成批准关系。** 描述变化虽然可能不改变候选分组，仍会改变完整指纹并停止使用旧批准，除非新的完整指纹已经被独立审核纳入白名单。

原始定义仅用于内存计算。关系磁盘记录保存来源 ID、已审核完整指纹列表、账号组、版本、有效期、优先级、超集核验标记及业务结论，不保存完整 schema、原始响应、调用参数、Header 或凭据。

## 版本化来源关系

关系分别声明 `candidate/approved`、revision、enabled、有效起止时间和逐成员指纹白名单。批准记录必须包含返回语义、计费、限流、数据新鲜度结论，以及审核时间和证据哈希；没有从一次相同响应推导完整业务等价。

记录位于 P1-02 的显式 profile 域下 `source_relations` 独立目录，按账号组和关系 ID 分隔。使用同一原子发布及 revision CAS 协议，重复写幂等，竞争写不覆盖，损坏/未知版本和非连续历史阻断读取。已有连接、凭据、治理及会话模式记录不迁移。

`approveSourceRelation` 由可信维护流程注入，默认始终拒绝启用的批准记录。候选不会被自动提升；停用某关系不需要重新批准，但重新启用仍需要批准。测试里的批准回调只接受合成账号，没有打开当前生产存储。

独立停用或到期会停止该关系的合并，原始工具可重新作为独立、未合并来源展示；旧关系 capability ID 的请求被拒绝，不会暗换成别的组。原始工具仍要通过权限及之后的只读审核。完整指纹未知变化会隔离受影响的批准成员，不继续套用旧关系。重叠批准不做传递合并，冲突关系会被隔离，不影响其他能力。

## 选择与权限语义

选择前通过 P1-03 的准备前权限接口检查当前连接、授权/状态、Workspace、治理、原手动激活及 Host 注册状态。该接口读取限制前的注册名称，不因本智能层隐藏工具而误判“不可发现”；本层的准备集不是额外授权。

默认选择顺序为：可信用户明确来源 > 当前 Agent 最近成功且仍有效的来源 > 已核验且可用的超集入口 > 固定优先级及稳定 ID。逐能力选择，不整条隐藏连接；独有工具和新增独有能力保留。对 `qcc-risk` 的禁止不会自动扩展成 `qcc-company` 的同类能力禁止，原治理语义不变。

搜索旧名称、标题或描述时，已批准有效组只返回首选入口及当前可发现别名，不因此加载原入口。候选仍分别展示，手动未激活工具可发现但不能被自动选作可加载来源，未在 Host 注册的缓存工具也不能通过等价关系获得可用资格。

模型请求只能提交 capability ID，不能通过 `source`、`explicit=true` 等声明证明用户意图。明确来源或比较指令来自另一个可信回调，收据绑定真实 Agent/SessionId、账号组、能力组、精确来源和当前完整指纹，并包含有效期及证据哈希。本期没有从聊天文本猜测或实现生产确认 UI。

用户指定来源被禁时拒绝，不改选其他来源。仅同一有效能力组内的可信“比较”指令允许同时选择多个来源，结果带预算例外标记；该标记不是自动放宽预算。失败结果通过可信 Host hook 记录，之后的选择保持阻断并返回备选，直到收到新的明确指令，不自动换源重试；并发比较中另一来源成功不会误清失败锁定。成功/失败偏好仅保留在当前 Agent 内存，恢复和子 Agent 不继承。

选择结果是待复核的计划，包含精确来源、完整指纹、关系 revision 和决策摘要；不会加载、调用或改变 Host 注册。`validateSelection()` 重新读取当前状态，同时检查计划未被改写；它不是跨步授权租约。P1-05 在准备提交前必须复核，原生执行仍须遵守 P1-03 guard。

## P1-05 准入与剩余边界

P1-04 已通过本次退出检查，可以进入 P1-05 开发。P1-05 应实现单次 prepare：按当前权限和来源计划选择少量工具，在提交前复核指纹与关系版本，原子更新当前 Agent 的内存准备集，并从下一次 Host resolve 生效。

**等价批准不等于只读审核。** 自动 prepare 必须额外取得绑定当前完整指纹的只读审核依据，不能使用 `get_` 前缀、远端 `readOnlyHint` 或同 schema 推断。未经只读审核、越界、未注册或过期关系要给出明确失败，不能降级成全量注入。

本次没有实现 prepare、真实原始定义生产接入、生产意图确认 UI、真实业务等价 canary、PTC 或批次资源保护。原始数据及可信意图接入、真实关系核验、模型收益和灰度仍须在后续授权与集成验收范围内完成；不据此启用生产智能模式或宣称已达到 Token 降幅目标。
