# 在 DSH 会话中试用 MCP 工具

要试用连接器，请先完成连接和所需授权。详情页可以查看已发现的工具、工具说明和已缓存的输入参数结构。点击「检查连接」可以检查连接状态，点击「重新发现工具」可以更新工具清单。这两个操作都不会执行所选业务工具。

## 从示例 Prompt 开始

1. 在连接器详情页选择示例 Prompt，点击「去试试」或该 Prompt 的发送按钮。插件会在当前工作区创建或复用一个空白会话，将文本写入草稿。若原会话已有未发送的文字或附件，原草稿会保留。
2. 核对服务、输入内容和实际操作范围，然后自行发送。也可以直接在 DSH 会话中描述任务，例如请模型用已连接的服务查询一项公开数据。
3. 模型在会话中选择是否调用可用工具。若 Host 请求审批，请核对本次操作后再决定是否允许。对于写入、删除或可能计费的工具，先确认目标和影响范围。执行结果在会话中查看。

## 执行与审批的边界

当前详情页没有填写参数并立即执行工具的入口。业务调用由 DSH Host 在会话中调度，适用当前工作区的工具权限和审批策略。看到工具的参数结构，表示客户端已获得相关元数据。要确认当前账号是否能执行某项操作，还需查看该次调用的结果。
