# 首批真实核验的验收步骤与请求预算

本表是分段执行方案，**不是新增真实请求、批准、信任根部署或发布的授权**。第一段已按用户随后给出的明确授权于 2026-11-16 完成，见 [当前采集报告](../../SMART-MODE-CURRENT-METADATA-REVIEW.md)。其余阶段尚未执行；核验及验收决定由用户本人负责。

## 第一段 更新当前元数据和来源身份

本次已在独立临时 profile 核对当前账号单个 grant 下六个官方企业 Server，并完成一轮原始 tools/list。首个初始化曾返回 401，随后外部凭据更新后再执行完整一轮，无脚本刷新令牌或自动重试。下表为后续同范围更新的预算约定；本次实际计数在采集报告单独列明。

| 项目 | 方案上限或条件 |
| --- | --- |
| initialize / initialized | 每个 Server 各一次，六路合计各六次 |
| tools/list | 每个 Server 首轮一页，合计六次；若仍有 cursor，停止并另记分页预算，不冒称目录已完整 |
| OAuth | 不自动刷新凭据、不重新授权、不扩大 scope；遇到鉴权失败停止 |
| 业务、模型 | 均为零；不执行 tools/call，不发送聊天消息 |
| 传输 | 精确端点与 transport 围栏，不转发凭据到重定向或其他地址 |
| 输出 | 当前绑定、11 个工具的完整指纹、时间和脱敏差异；原始定义仅在核验进程内使用 |

历史完整指纹可以作差异对照。当前 sourceId 则必须按当前 accountRef/groupId/connection key/Server/raw name 重新取得，尤其不能复制旧 group 的 sourceId。出现缺失工具、歧义、端点变化或不兼容定义时停止对应项，不补造字段。

## 第二段 人工审核与真实签名证据交付

先处理 QCC-RO-001 的业务只读核验。由用户本人填写单工具核验表，补原始定义、业务副作用、返回语义、计费限流、期限和独立证据摘要。其余五个主入口和五个公司侧入口可分别跟进，不需要首轮全部批准。

人工通过后再单独确认：审核方身份及公钥、私钥在独立审核环境保管、目标临时 profileBinding、签名包范围、revision 和期限。真实公钥预置与真实包交付需要另行明确授权，不写当前 DSH 配置，不自动覆盖现有信任根或清除接收记录。文件格式沿用 [可信证据交付协议](../../SESSION-TOOL-INJECTION.md#可信只读证据交付尚未发布)。

交付后的初次验证仅检查签名、绑定、准备可见性、撤回、过期、重启和回放拒绝；业务执行及真实模型仍保持零。未通过者维持未核验，不能用合成记录、前缀、readOnlyHint 或自填哈希补齐。

## 第三段 首个真实只读调用

以下字段全部明确并获授权后才执行。优先选择 QCC-RO-001，而非一次开放所有入口。

| 项目 | 待确认值 |
| --- | --- |
| 真实工具 | qcc-company / get_company_registration_info；当前身份和完整指纹待核对 |
| 测试主体与精确参数 | 用户指定，当前留空；不猜测主体、参数名或字段值 |
| 调用预算 | 提议最多一次业务调用；自动重试、失败换源、批量查询均为零 |
| 费用/额度与时间窗口 | 用户确认，当前留空 |
| 真实模型请求 | 零，直接在受控链路验证已核验来源 |
| 停止条件 | 鉴权/限流/定义变化、参数或返回不符、发现副作用、费用边界未知、实际范围越界 |
| 保存 | 只保存必要的脱敏结果与摘要，业务样本在用户指定的受控位置维护，不进仓库或证据包 |

调用成功只能证明该来源、该参数和该时点的这一次路径。失败时不自动重试、换源或扩大授权；恢复静态兼容视图也不改变已有治理拒绝。不得将一次成功替代其他来源的核验。

## 后续可选的两组验收

**跨来源比较：** 五对关系各自完成静态核验并获调用授权后，提议每对同一已确认输入各调用两侧一次，共最多十次。每组单独记录实际预算；不默认复用过期样本或自动重试，不因为比较成功就自动签发来源关系。返回语义、计费、限流、新鲜度和 `_registration_tool` 的含义仍需人工结论。

**真实模型 A/B：** 另行授权后，可先提议 v4-pro、flash 各做一次全量基线与一次智能初始头，共四次模型请求；需事先确认真实模型路由、请求次数、费用和失败停止条件。通过 Host 执行限制确保业务调用为零，不能只依赖提示词“不要调用工具”。该最小 A/B 只验初始头，准备后常用工具与临界预算另定用例，不冒称已经覆盖。

费用、usage、缓存和请求大小分别记录；组内预算只计当前账号六个企业 Server 与两个常驻入口。其他连接不纳入本轮优化分母，不对整个会话作 90% 下降承诺。

## 不属于本表的自动动作

本表不会安装到当前 DSH、启用生产智能模式、批准全部候选、部署签名私钥、修改 Host 审批、合并 PR 或发布。真实核验与签发完成之后，再安排主线对齐、最终审阅/CI、发行安装升级及回退验收。
