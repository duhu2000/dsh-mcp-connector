# 单工具真实只读核验表

每个入口单独复制并填写。首批编号、历史身份和责任角色见 [登记表](review-register.json)。填写结果本身不会写入运行时审核记录，不构成业务执行授权。

## 工具与当前绑定

| 字段 | 待填写值 |
| --- | --- |
| 核验编号 | QCC-RO-___ |
| 业务核验人、独立证据整理/签发人 | 用户本人 |
| 核验日期与时区 | 待填，时间精确到毫秒时使用 UTC epoch ms |
| Server / raw name / public name | 从登记表定位，再核对当前值 |
| 当前账号引用 / grant / connection key | 待在隔离环境核对；只记录身份引用，不记录凭据 |
| groupId | qcc-enterprise-six-v1，待与当前运行 scope 核对 |
| 当前 sourceId / 完整 definitionFingerprint | 待采集和核对；不得使用历史 sourceId 代填 |
| 原始定义采集时间、提供方版本 | 待填；版本未提供时明确记为未提供 |
| 原始定义核对证据引用/摘要 | 待填；完整定义不进入本登记表 |

## 必须完成的核对

| 检查项 | 证据要求 | 结果与证据引用 |
| --- | --- | --- |
| 来源与授权 | 正确账号、六服务组、精确 endpoint/transport、当前 grant 与连接身份；不扩大授权 | 待核验 |
| 完整定义 | 核对真实原始 name、输入/输出 schema（若提供）、annotations 及所有扩展字段；保留 `_registration_tool` | 待核验 |
| 参数语义 | 必填项、主体匹配、枚举/范围、分页、时间和错误语义；不根据工具名猜参数 | 待核验 |
| 业务副作用 | 服务商材料或独立证据确认：是否创建/修改/删除资源，是否触发任务、导出、订阅、消息或其他动作 | 待核验 |
| 返回语义 | 字段、单位、空结果、分页、新鲜度；outputSchema 未提供时补正式字段说明或授权样本证据 | 待核验 |
| 权限边界 | Workspace、治理拒绝、连接停用、手动激活要求及 Host 审批都继续生效 | 待核验 |
| 计费与限流 | 是否扣量、失败/分页/重试是否收费、限流维度及费用确认；与只读结论分开记录 | 待核验 |
| 定义变化 | input/output、annotations、注册扩展或来源绑定变化后重新计算完整指纹并重审 | 待核验 |
| 独立审核证据 | 证据来自插件/模型之外的人工核验；记录资料版本、核验日期与审核方摘要 | 待核验 |

不要将正常查询日志或计费自动归类为业务写入；也不要因没有显式写入参数就认定无副作用。无法证明的项保留未知。

## 人工结论与有效期

| 字段 | 待填写值 |
| --- | --- |
| 人工结论 | 未核验；后续只能明确填写：通过只读核验 / 拒绝 / 证据不足 |
| 结论理由及证据引用 | 待填 |
| independent dossier SHA-256 | 待填，不使用任意字符串替代真实证据摘要 |
| reviewerHash / reviewedAt | 待填，由真实审核身份和核验时间确定 |
| validFrom / expiresAt | 待填；不得超过签名包时限，时间必须与实际审核计划匹配 |
| 再核验条件 | 定义/来源/授权变化、到期、服务商行为变化；具体触发条件待填 |
| 签名包准备情况 | 尚不可签发；上述证据及当前身份完整后再单独处理 |

## 后续调用必须另填

测试主体、精确参数、允许范围、调用次数上限、费用确认、时间窗口、停止条件和结果保存位置均为待填。不要填写 Token、Cookie、Authorization Header 或完整业务响应；只保留脱敏结论和必要证据摘要。
