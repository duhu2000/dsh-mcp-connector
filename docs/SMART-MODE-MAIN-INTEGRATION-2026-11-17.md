## 冲突与主线保留

唯一冲突为 package.json 的 lint 字段。合并采用双方检查的有序并集，共 72 条 node --check，保留智能模式、来源/证据模块检查，以及主线 Zerone 两个文件的检查。主线的 0.2.110 版号、bin/files、已发布桥接实现、文档及发行媒体一并保留，没有用旧版元数据覆盖主线。

本任务没有新增产品功能。六服务智能绑定、Host 版本边界、权限、只读核验、来源选择、按需加载、预算/TTL 与兼容回退保持不变；对应 lib/smart-mode-*、lib/read-only-evidence.js、lib/source-relations.js、lib/source-selection.js 和 ui/smart-mode.* 与 7dfebc6 逐文件一致。Zerone 是主线既有功能的继承，不是本任务扩展智能连接组。

发布白名单由旧包的 144 文件变为 146 文件，新增的是主线的 lib/zerone-bridge.js 与 scripts/zerone-bridge.mjs。完整新包不再宣称“143 个非 package.json 文件全部未变”，应按主线继承与本任务变更分别判断。
